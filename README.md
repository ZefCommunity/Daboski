Student Web Development Class

Project Overview

We are building a collaborative website for a student technology community. Each student will create one complete webpage in this shared repository.

Project Rules

* Each student must work on their own Git branch.
* Each student must create a complete webpage using HTML and CSS.
* Use your assigned filenames so your work does not conflict with another student’s work.
* Commit your work with a clear commit message.
* Push your branch to this repository.
* Open a Pull Request (PR) to merge your work into main.
* Do not commit directly to main.
* The instructor will review Pull Requests before merging them.

Technologies

* HTML
* CSS
* Git
* GitHub

Workflow

1. Clone the repository.
2. Create and switch to your assigned branch.
3. Build your assigned webpage.
4. Commit your changes.
5. Push your branch to GitHub.
6. Open a Pull Request into main.
7. Wait for the instructor’s review and approval.
